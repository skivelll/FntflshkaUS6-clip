FntflshkaUS6 clip — Windows x64

Распакуй весь архив в обычную папку и запусти FntflshkaUS6 clip.exe.
Папка _internal должна оставаться рядом с exe. Python и PlatformIO не нужны.
Не запускай приложение прямо внутри ZIP.

Подключи заколку USB-кабелем. При подключении все сцены загружаются в RAM,
после чего выбор preview происходит без повторного чтения платы.
Закрой serial monitor и другие приложения, занимающие COM-порт.
Если связь не восстановилась, нажми «Переподключить» или переподключи USB.
Загрузка после обрыва автоматически не повторяется: сначала проверь список сцен.

Настройки и журнал сохраняются в каталоге данных пользователя, отдельно от exe.
Точный путь журнала виден в блоке «Устройство и журнал».
Кэш картинок хранится только до закрытия приложения.

GIF требует firmware 1.6. При добавлении выбирается компактный профиль
128x128/96x96 или полный экран 320x172. Лимит файла 512 KiB; полный профиль
вмещает до четырёх кадров и работает примерно до 3 кадров/с, с возможной
видимой полосной перерисовкой. Длинный GIF не обрезается автоматически:
выбери диапазон/шаг в «Настройки GIF…». Preview и библиотека работают из RAM.
Для анимационных сцен используй эту новую версию приложения.

Демо без платы: запусти exe с аргументом --mock.
Проверка сборки без USB: --mock --smoke-test report.json

Сборка не подписана цифровой подписью. Windows может показать SmartScreen.
Не отключай системную защиту. Проверяй источник сборки и build-info.json.
