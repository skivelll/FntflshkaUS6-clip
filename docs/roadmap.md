# План следующих фаз

Windows migration, scene manager, RAM cache и portable Windows release завершены
и проверены на реальной плате. Последующие фазы запускаются отдельными задачами.

## 1. Редактор изображений и память — завершена

Все четыре пункта реализованы; сохранение на LCD и непрерывный drag/wheel preview
подтверждены пользователем. 64 desktop + 8 tools tests прошли. Следующая фаза —
локальная библиотека и резервные копии.

Перенесена перед библиотекой по пользовательским требованиям:

1. Перетаскивать изображение в preview курсором; изменения выражены в пикселях LCD,
   независимо от размера окна и Windows DPI.
2. Масштаб 10–400%: ползунок, ввод точного процента и колесо над изображением.
   Колесо сохраняет точку изображения под курсором с точностью целого пикселя.
3. Редактировать уже загруженную сцену без нового исходного файла: брать verified
   RGB565 из RAM, дать сдвиг/масштаб и явно подтвердить безопасную замену того же ID.
   Сохранить имя/порядок; отмена не меняет плату. Оригинальный PNG и обрезанные части
   восстановить невозможно. Не вводить protocol/asset v2.
4. Полоса LittleFS: занято/свободно, место под новый файл и прогноз удаления.
   Указывать приблизительность до операции и фактический free после ACK.
   При замене учитывать место под новый файл рядом со старым A/B.

Дальнейшие улучшения редактора: undo/redo, пресеты. В этой фазе есть отмена draft;
история действий и локальное хранение исходников относятся к следующим задачам.

## 2. Локальная библиотека и резервные копии — завершена

Экспорт/import/offline preview и восстановление с предварительной копией реализованы.
79 desktop + 8 tools tests прошли; восстановление на LCD и просмотр при отключённом
USB подтверждены пользователем. Следующая фаза — автоматическая смена статичных
сцен; она пока не начата.

Экспорт одной/всех сцен с именами/порядком, работа с коллекциями без платы,
проверка архивов и preview восстановления с конфликтами ID и расчётом места.
Asset v1 остаётся внутри desktop-контейнера. Не удалять сцены молча.
Исходники и параметры редактирования можно сохранять отдельно от готового RGB565,
чтобы будущие изменения не начинались с уже обрезанного изображения.

## 3. Автоматическая смена статичных сцен

Плейлисты, интервалы и автономное воспроизведение при закрытом приложении.
Потребуется отдельная firmware-задача, проверки RESET, удаления сцен из плейлиста
и сохранения настроек. Порядок текущей коллекции не является слайд-шоу.

## 4. Анимации

Сначала измерить RAM, скорость LittleFS/USB и отрисовки. Затем отдельно согласовать
формат и лимиты анимационных assets, сохранить совместимость статичного v1.
GIF — входной формат desktop, не заранее выбранный формат на ESP32.
Не переходить на full-screen framebuffer без отдельного технического решения.

## 5. Автономность и управление

Изучить реальную схему кнопок/питания, затем управление сценами, яркость, аккумулятор
и сон. Измерить время работы/нагрев и проверить LittleFS при потере питания.
Wi-Fi/Bluetooth/Flash 8 MB не входят автоматически ни в одну фазу.

## 6. Публичное распространение

Версии/история изменений, иконка/сведения о приложении, диагностика и проверки
на чистых Windows 10/11. Installer/цифровая подпись — при необходимости;
portable ZIP сохраняется. Можно вести параллельно после выбора состава первого релиза.
